Planning/estimation only, not for navigation

Global bathymetry grid, ~450m resolution. Public domain data from GEBCO — useful for open-ocean context, not detailed enough to trust in shallow coastal water or for anything safety-related.

Worldwide tidal zones from the FES2014 model (Aviso+/CNES) — blue = microtidal (<2m), orange = mesotidal (2–4m), red = macrotidal (>4m). Coarse classification only -- for a specific port's actual range, use "Check tidal range" below instead.

OpenStreetMap community data — green = operational, orange = under construction, grey (dashed) = planned. Not an authoritative register; recently announced projects may be missing. Click a marker to use it as your start/destination and see its details.

Click two points on the map to draw a line. Any part of the routing network crossing it is blocked (weight set to infinity) until you remove it -- useful for testing "what if this passage were closed" scenarios. This is a shared, server-side test tool, not a real closure, and isn't specific to your session.

Click the map to set points directly: first click = start, second click = destination. Once a route is drawn, drag its vertices (or click the line to add one) to correct it.
